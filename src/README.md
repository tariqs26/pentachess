## Source Code

This folder holds the code for the project.

There are three subdirectories:
- `GameMaker Demo`: holds the code for the GameMaker demo. It is not involved with the final production code.
- `frontend`: holds the main production code, including frontend, authentication, and database code. See its `README.md` for setup instructions.
- `server`: holds the code for socket.io connections used in online matches. See its `README.md` for setup instructions.
